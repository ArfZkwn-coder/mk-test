# Teh Tarik

Teh tarik ("pulled tea") is a sweet, milky Malaysian tea, known for the froth made by pouring it back and forth between two cups.

![A glass of frothy teh tarik](../img/drinks/teh-tarik.jpg)

*Teh tarik. Photo: Jonathan Lin, CC BY-SA 2.0 (see [Photo credits](#photo-credits)).*

!!! tip "Pulling"
    Pour from a height for more froth.
